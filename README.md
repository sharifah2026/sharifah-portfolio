# معرض إنجاز شريفة للأعمال الإدارية — تحديث نظام نور

هذه نسخة من الموقع تضيف ست بطاقات منفصلة في تصنيف «نظام نور»، مع دعم عرض الصور وفتح ملفات PDF للشواهد. الشواهد **غير مرفقة** حتى تضاف بعد مراجعة الخصوصية.

## إضافة شاهد
1. ضعي صورة أو ملف PDF بعد حجب البيانات الشخصية في مجلد `assets/`.
2. افتحي `script.js` وابحثي عن بطاقة الإنجاز.
3. بدّلي `image:''` إلى `image:'assets/اسم-الصورة.jpg'`، أو `evidence:''` إلى `evidence:'assets/اسم-الملف.pdf'`.
4. ارفعي جميع الملفات إلى جذر مستودع `sharifah2026/sharifah-portfolio`، مع استبدال الملفات القديمة. لا ترفعي ZIP كما هو.
5. انتظري نشر GitHub Pages وافتحي https://sharifah2026.github.io/sharifah-portfolio/ .

**تنبيه:** GitHub Pages عام. لا تنشري أي مستند يحتوي على بيانات طالبات أو موظفات أو معلومات دخول أو رموز QR تكشف بيانات خاصة.
