# معرض إنجاز شريفة للأعمال الإدارية

موقع عربي RTL متجاوب، يعمل مجانًا على GitHub Pages.

## النشر
1. ارفعي ملفات المجلد الأربعة إلى جذر المستودع `sharifah-portfolio` (استبدلي النسخ القديمة).
2. من Settings > Pages اختاري Deploy from a branch، ثم main و /(root).
3. انتظري اكتمال النشر.

## التعديل
- أضيفي صور الإنجازات العامة إلى مجلد `assets` واكتبي مساراتها في `script.js`.
- غيّري بريد التواصل التجريبي في `script.js` قبل استخدام زر البريد.
- لا تنشري بيانات الطالبات أو الموظفات أو المستندات الداخلية السرية.
