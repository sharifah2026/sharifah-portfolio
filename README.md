# معرض إنجاز شريفة للأعمال الإدارية
موقع معرض إنجاز شخصي عربي، RTL، ومتجاوب. يعمل دون خادم أو اشتراك.

## المعاينة
افتحي ملف `index.html` في المتصفح.

## التخصيص
1. عدّلي النصوص التعريفية في `index.html`.
2. عدّلي البريد `contactEmail` في `script.js` (البريد الحالي تجريبي).
3. عدّلي قائمة `projects` في `script.js` لإضافة الإنجازات أو حذف النماذج.
4. ضعي الصور في مجلد `assets`، ثم أضيفي المسار في خاصية `image` مثل `assets/work1.jpg`.
5. لا تضعي أرقام هوية أو بيانات طالبات أو صور أشخاص دون موافقة مناسبة في موقع عام.

## النشر مجانًا على GitHub Pages
1. سجّلي دخولك إلى github.com أو أنشئي حسابًا مجانيًا.
2. أنشئي مستودعًا عامًا (Public) جديدًا باسم `sharifah-portfolio`.
3. ارفعي `index.html` و`style.css` و`script.js` ومجلد `assets` إلى جذر المستودع (وليس داخل مجلد إضافي).
4. من Settings > Pages اختاري Deploy from a branch ثم Branch: main و Folder: /(root) واضغطي Save.
5. بعد اكتمال النشر سيظهر الموقع على `https://enjaz-sharifah.github.io/sharifah-portfolio/` بعد استبدال USERNAME باسم مستخدم GitHub.
6. لتحديث الموقع، عدّلي الملفات في المستودع وستُنشر التغييرات بعد اكتمال البناء.

ملاحظات: GitHub Pages يستضيف المواقع الثابتة. رابط `github.io` مجاني، ولا حاجة لشراء نطاق. يعتمد النشر على حدود وشروط GitHub Pages السارية. النماذج الموجودة في المعرض أمثلة وليست إنجازات موثّقة.
